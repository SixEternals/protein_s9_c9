## 2. `QA2.md` — 早期方向讨论

核心讨论（2026-05-16）：
> "多视角端到端融合 vs RNA-FM + 先验特征融合，是否认可先做多视角端到端融合？"

当时的共识：先做多视角端到端融合（Region + Run），RNA-FM 增强版留到后面。

> **实际演进**：项目直接进入了 RNA-FM + Run 路线（BL4/BL5），Region 编码在 CCLMoff 上被证明增益有限（BL3-Region-only AUPRC=0.207），因此后续主线**放弃了 Region**，保留了 Run + RNA-FM + PAM。早期讨论的方向与实际演进不完全一致。
