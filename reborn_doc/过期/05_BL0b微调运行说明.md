# BL0b 微调运行说明

## 目的

BL0b 用来回答一个很直接的问题：

> 在同一份 CCLMoff CSV、同一个 `sgRNA_type_group` 严格切分下，把 RNA-FM 从 frozen 改成 full fine-tune，是否能显著超过 BL0a-frozen。

当前对照基线：

| Baseline | RNA-FM | Trainable Params | Test AUROC | Test AUPRC |
|:---|:---|---:|---:|---:|
| BL0a-formal-frozen-v1 | frozen | 41,089 | 0.840561 | 0.072718 |
| BL0b-finetune-v1 | full fine-tune | 约 99.56M | 待运行 | 待运行 |

BL0b 仍然只是 RNA-FM + CCLMoff-style MLP head，不包含 Region encoder、Run encoder、Cross-Attention 或 Gated Fusion。

## 关键配置

正式配置文件：

```text
configs/bl0b_finetune.yaml
```

与 BL0a-frozen 的核心区别：

| 参数 | BL0a-frozen | BL0b-finetune |
|:---|:---|:---|
| `rnafm.freeze` | `true` | `false` |
| `training.rnafm_learning_rate` | 实际不训练 RNA-FM | `0.0005` |
| `training.head_learning_rate` | `0.001` | `0.001` |
| `training.warmup_epochs` | `0` | `5` |
| `training.gradient_clip` | 未启用 | `1.0` |
| `training.epochs` | `5` | `10` |

训练器仍然使用：

```text
scripts/train_bl0a_formal.py
```

文件名保留了 BL0a，是因为它已经成为 BL0 RNA-FM 系列的正式训练入口。BL0b 通过 config 切换，不复制训练代码。

## 运行顺序

先跑 dry-run，确认 full RNA-FM backprop、DDP 外壳、checkpoint 写出都能通：

```bash
cd /data/zwf/code1/reborn_seed
CONFIG_PATH=configs/bl0b_finetune_dryrun.yaml NPROC_PER_NODE=1 CUDA_VISIBLE_DEVICES=0 bash run/run_bl0b_finetune.sh
```

dry-run 通过后，再跑正式 2-GPU DDP：

```bash
cd /data/zwf/code1/reborn_seed
bash run/run_bl0b_finetune.sh
```

等价显式写法：

```bash
cd /data/zwf/code1/reborn_seed
CONFIG_PATH=configs/bl0b_finetune.yaml NPROC_PER_NODE=2 CUDA_VISIBLE_DEVICES=0,1 bash run/run_bl0b_finetune.sh
```

如果 2-GPU OOM，优先把 `configs/bl0b_finetune.yaml` 里的：

```yaml
training:
  batch_size: 128
```

改成：

```yaml
training:
  batch_size: 64
```

其他参数先不动。

## 输出文件

正式运行输出目录：

```text
results/bl0b_finetune/
```

关键产物：

| 文件 | 内容 |
|:---|:---|
| `results/bl0b_finetune/summary.json` | 完整运行摘要、测试集指标、参数量、显存、split 信息 |
| `results/bl0b_finetune/report.md` | 人类可读汇报 |
| `results/bl0b_finetune/epoch_metrics.csv` | 每个 epoch 的 val AUROC/AUPRC/loss |
| `results/bl0b_finetune/checkpoints/best.pt` | 按 val AUPRC 选出的最佳 checkpoint |
| `results/bl0b_finetune/checkpoints/last.pt` | 最后一个 epoch 的 checkpoint |
| `results/experiments.csv` | 正式实验记录追加行 |
| `runs/job_logs/bl0b_finetune_*.log` | 终端日志 |

查看结果：

```bash
cat results/bl0b_finetune/summary.json
cat results/bl0b_finetune/report.md
cat results/bl0b_finetune/epoch_metrics.csv
tail -n 5 results/experiments.csv
```

## 判断标准

这里的判断必须和 BL0a 使用同一个 `sgRNA_type_group` 切分比较。

| Test AUPRC | 判断 |
|:---:|:---|
| `< 0.15` | 需要排查 full fine-tune 是否真的生效，或 split/token/label 流程是否有问题 |
| `0.15 - 0.35` | 有提升但偏低，可能是严格 group split 导致，仍可作为后续 BL3/BL4/BL5 的参照 |
| `0.35 - 0.50` | 效果良好，说明 RNA-FM fine-tune 明显有效 |
| `>= 0.50` | 效果优秀，但需要重点确认没有 split 泄漏或评估口径变化 |

注意：`0.4 - 0.5+` 是参考 CCLMoff 论文口径的乐观预期。我们这里使用更严格的 `sgRNA_type_group` 切分，指标可能低于论文 split。

## 完成后

正式结果出来后，先不要自动 tag。先人工核对：

```bash
cat results/bl0b_finetune/summary.json
cat results/bl0b_finetune/report.md
tail -n 5 results/experiments.csv
```

确认无误后，再由用户明确授权执行 tag，例如：

```bash
git tag -a BL0b-finetune-v1.0 \
  -m "BL0b: RNA-FM fine-tuned + MLP | AUROC=x.xxxx AUPRC=x.xxxx | freeze=false | sgRNA-safe split"
```

项目规则要求：未经用户确认，不自动执行 `git tag`、`git commit` 或 `git push`。
