# BL0a 正式训练运行说明

> 目标：运行 BL0a formal frozen baseline。  
> 模型：RNA-FM frozen encoder + CCLMoff-style MLP head。  
> 输入：CCLMoff Figshare v2 CSV。  
> 切分：`sgRNA_type` group-safe split，避免同一个 sgRNA_type 出现在 train/val/test 多个集合中。

---

## 1. 运行命令

在项目根目录运行：

```bash
bash run/run_bl0a_formal_frozen.sh
```

默认使用：

```text
CONFIG_PATH=configs/bl0a_formal_frozen.yaml
CUDA_VISIBLE_DEVICES=0
```

换 GPU：

```bash
CUDA_VISIBLE_DEVICES=1 bash run/run_bl0a_formal_frozen.sh
```

只做极小 dry-run 自检：

```bash
CONFIG_PATH=configs/bl0a_formal_dryrun.yaml bash run/run_bl0a_formal_frozen.sh
```

注意：

- 正式 bash 会先检查 CUDA。
- 如果 CUDA 不可用，脚本会直接退出，不会在 CPU 上跑全量 RNA-FM。
- dry-run 的实验记录写入 `results/experiments_dryrun.csv`。
- formal frozen 的实验记录写入 `results/experiments.csv`。

---

## 2. 正式配置

正式配置文件：

```text
configs/bl0a_formal_frozen.yaml
```

关键设置：

```yaml
dataset:
  csv_path: data/cclmoff/09212024_CCLMoff_dataset.csv
  max_rows: null

split:
  strategy: sgRNA_type_group
  group_column: sgRNA_type
  train_fraction: 0.8
  val_fraction: 0.1
  test_fraction: 0.1

rnafm:
  checkpoint_path: data/rnafm/checkpoints/RNA-FM_pretrained.pth
  freeze: true

training:
  epochs: 5
  batch_size: 256
  eval_batch_size: 512
  precision: bf16
  monitor: auprc
```

解释：

- `freeze: true`：只训练 MLP head，RNA-FM 只做前向表征。
- `precision: bf16`：适合当前 Blackwell GPU；评估时脚本会转回 float32 计算指标。
- `monitor: auprc`：按验证集 AUPRC 选择 best checkpoint。

---

## 5. 重要限制

1. 这是 BL0a，不使用 Region encoder 或 Run encoder。
2. 当前 `<sep>` 不是 RNA-FM alphabet 原生 token；项目 tokenizer 将 `"<sep>"` 压成单个 `<unk>` delimiter。
3. `label=0` 只表示 `unobserved_candidate`，不是实验验证安全。
4. 当前正式配置是 frozen RNA-FM；如果要 fine-tune RNA-FM，需要另起配置，不要直接覆盖这个 baseline。
5. 当前脚本是单卡正式训练器，不是 DDP。先用单卡跑出可解释 baseline，再决定是否补 DDP。
