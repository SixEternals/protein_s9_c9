## 五、AI 查阅纪律

1. **承接新任务前**：先读 `reborn_doc/todo.md` → 再读 `reborn_doc/0_文档导航与阶段对照表.md`（本文档）→ 按需深入各阶段文档。
2. **写报告/论文时**：实验结论必须引用最新总报告（`38_` / `39_` / `40_`），不得引用 `reborn_doc/过期/` 或 `doc/` 中的原始历史文件。
3. **代码开发时**：技术细节（坐标约定、PAM 提取方式、Run 编码范围）以 `reborn_doc/1. 大纲拟定.md` 和 `AGENTS.md` 为准。
4. **不确定时**：如果两份文档说法冲突，以**编号更大、时间更近**的文档为准；以 `todo.md` 为最终仲裁。
