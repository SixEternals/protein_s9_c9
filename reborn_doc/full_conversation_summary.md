## 第一部分：基础知识（生物学背景）

### 1.1 CRISPR/Cas9 是什么

CRISPR/Cas9 是一种基因编辑工具，最初在细菌和古菌中发现，是它们的适应性免疫系统，用来记住并消灭入侵的病毒（噬菌体）DNA。人类将其改造为基因编辑工具。

核心组件：
- **Cas9蛋白**：一把"分子剪刀"，负责切割DNA
- **sgRNA（单链向导RNA）**：导航系统，20个碱基长度的RNA序列，负责找到目标DNA位置

sgRNA的两部分结构：
- **20nt引导序列（spacer）**：人类可以自由设计，与目标DNA互补配对
- **scaffold支架**：固定结构，与Cas9蛋白结合

工作原理：
1. sgRNA的20nt引导序列与基因组DNA某位置互补配对
2. Cas9蛋白将sgRNA-DNA复合物"按住"
3. 如果配对足够稳定，Cas9切割DNA双链

### 1.2 碱基配对规则

DNA双链的互补配对：
- A（腺嘌呤）↔ T（胸腺嘧啶），通过2个氢键连接
- G（鸟嘌呤）↔ C（胞嘧啶），通过3个氢键连接

RNA与DNA配对时：
- sgRNA中的U对应DNA中的A
- 其他规则相同（G↔C，A↔A在RNA-DNA中）

### 1.3 什么是"错配（Mismatch）"

错配 = sgRNA和DNA配对时，某个位置上碱基没有按规则配对。

举例：
```
sgRNA:  A-C-G-T-T-A
DNA:    T-G-C-A-T-T
        ↓ ↓ ↓ ↓ ✗ ↓
              ↑
        第5位：sgRNA是T，DNA也是T → T应该配A → 错配！
```

### 1.4 什么是"连续错配（Consecutive Mismatch）"

连续错配 = 多个错配位置**连在一起**，形成一个错配块。

对比：
- **分散错配**：`对-对-错-对-错-对-错-对`（错配之间隔着匹配位置）
- **连续错配**：`对-对-错-错-错-对-对-对`（错配连在一起）

生物学意义：
- 连续错配会在DNA双链上形成"鼓包"（Bulge）结构
- R-loop（Cas9切割前必须形成的中间结构）会在鼓包处卡住
- 连续错配对Cas9切割活性的影响**不是线性**的：连续2个错配和连续3个错配的风险等级差异很大
- 但分散错配（同样总数）对R-loop的阻碍相对较小

### 1.5 什么是"脱靶效应（Off-target）"

脱靶 = sgRNA认错了地方，找到了基因组中另一个"长得像但不是目标"的DNA位点，Cas9也一刀切下去了。

**关键理解**：脱靶不是"没粘上"，而是"粘错了地方还切了！"

三种场景：
1. **On-target（正靶）**：完全匹配，Cas9切了目标位置 → ✅正确
2. **Off-target（脱靶）**：有错配但Cas9容忍了，切了不该切的地方 → ❌有害
3. **不切（安全）**：错配太多，Cas9粘不住，没切 → ✅安全

脱靶的危害：
- 切到抑癌基因 → 细胞癌变
- 切到关键基因 → 细胞死亡
- 尤其在基因治疗中极其危险

### 1.6 Cas9的错配容忍机制

Cas9不是"零容忍"的。即使有几个错配，Cas9的"大手"（蛋白质正电荷沟槽）也能把sgRNA-DNA硬按在一起：

- 摆动碱基对（Wobble Pair）：如G-T/U也能形成2个氢键，形状扭曲但能粘
- 碱基堆积力：即使不配对的碱基，堆叠在一起也有稳定性
- 拉链式配对：从PAM附近开始逐步延伸，前面拉住后面就能跟上

所以关键是：基因组中存在大量"长得像但不完全一样"的序列，sgRNA会在这些地方结合并切割。

### 1.7 PAM区和种子区（Seed Region）

- **PAM（Protospacer Adjacent Motif）**：Cas9蛋白首先识别的短序列（NGG），像"敲门暗号"
- **Seed区（种子区）**：PAM附近的10-12个碱基（约16-20位），R-loop从这里启动
  - Seed区全匹配 → R-loop启动成功 → 即使远端有错配也可能切
  - Seed区有错配 → R-loop启动失败 → 大概率不切

## 第二部分：已有模型分析

### 2.1 大师兄论文（CRISPR-DeepFocus）核心要点

**论文核心**：关注种子区（Seed Region），用9-bit区域编码区分PAM区/seed区/普通区

**编码方案（9-bit区域编码）**：
- 前5位：碱基类型（A/T/C/G/-）
- 第6-7位：错配方向（匹配/错配/插入/缺失）
- 第8-9位：**区域标志**（00=PAM区，10=seed区，01=普通区）

**模型架构**：
- Inception + CA-Transformer
- CA-Transformer = Transformer + Channel Attention

**生物学直觉**：
- "PAM附近1-5bp匹配不上，R-loop根本启动不了"
- 让模型知道不同功能区域的重要性差异

**数据集规模**：约60万个样本

### 2.2 小师兄论文（ConMismatch9）核心要点

**论文核心**：关注连续错配片段的结构特征，用9-bit连续错配编码

**编码方案（9-bit连续错配编码）**：
- 前5位：碱基类型
- 第6-7位：错配方向
- 第8-9位：**连续错配状态**（00=匹配，01=单点错配，10=连续2个，11=连续3+）

**模型架构**：
- CNN + MI调制 + Run-Attn + Gated Fusion
- 多分支设计：第1-4位→CNN主干，第5-7位→MI调制，第8-9位→Run-Attn
- Gated Fusion：自适应权重融合不同分支

**生物学直觉**：
- "错配总数相同时，连续错配和分散错配对靶序列识别及切割的影响不同"
- 连续错配片段的长度、所在位置、边界特征都会对脱靶风险产生影响

**Gated Fusion 的关键**：
- 不是简单平均！每个样本的融合权重是动态计算的
- 门控网络根据输入特征自动决定"这个样本该听哪个分支的"

**数据集规模**：约60万个样本

### 2.3 CCLMoff 论文（2025年6月）核心要点

**论文信息**：
- 发表期刊：Communications Biology（IF=5.2，中科院一区Top）
- 单位：佛山大学唐冬生团队 + 深圳市卫生健康发展研究和数据管理中心
- 论文地址：https://www.nature.com/articles/s42003-025-08275-6
- 源码地址：https://github.com/duwa2/CCLMoff

**核心创新**：基于RNA预训练语言模型的通用脱靶预测

**模型架构**：
- 底座：RNA-FM（12层Transformer，640维隐藏层，~99M参数）
- 微调：MLP分类头
- 输入格式：[sgRNA序列] + [SEP] + [靶DNA伪RNA序列（T改U）]
- 输出：取[CLS]标记 → MLP → 脱靶概率

**RNA-FM预训练详情**：
- 训练数据：RNAcentral数据库2300万条RNA序列
- 训练方式：掩码语言模型（完形填空），遮住15%位置让模型猜
- 训练时间：1个月
- 硬件：8张A100 80GB GPU

**数据集规模**：
- 整合13种全基因组测序技术，21项研究
- 418条sgRNA，82,699个实验验证脱靶位点
- 9,521,638个训练样本（通过Cas-OFFinder生成负样本）
- 阳性/阴性比例1:26至1:4189（极端不平衡）

**性能指标**：
- CIRCLE-seq数据集：AUROC=0.985，AUPRC=0.520
- GUIDE-seq跨数据集验证：AUPRC=0.520
- DIG-seq：AUROC=0.985

**CCLMoff的关键发现**：
- 注意力权重自动集中在seed区（16-20位），与生物学理论吻合
- 无预训练版本（CCLMoff-Vanilla）AUPRC降至0.381，证明预训练的巨大贡献
- 表观遗传信息（CCLMoff-Epi）未显著提升性能

**CCLMoff的14个技术做法**：
1. RNA-FM预训练语言模型
2. 超大规模数据集（950万样本）
3. 多物种覆盖（人+鼠）
4. 多长度sgRNA（19/20/21nt）
5. 问答框架（sgRNA=问题，DNA=答案，[SEP]分隔）
6. 伪RNA化处理（DNA中T→U）
7. Bootstrap采样（每batch随机采样保证正负平衡）
8. 学习率分层（Transformer层5e-4，MLP层1e-3）
9. 学习率Warm-up（前5epoch从小到大升温）
10. 表观遗传扩展（CCLMoff-Epi版本）
11. 注意力可解释性分析
12. Leave-One-Dataset-Out验证
13. 端到端无人工特征
14. Cas-OFFinder预处理流水线

## 第三部分：模型融合讨论

### 3.1 简单加权融合（最浅的方案）

两个模型各自独立预测，然后加权平均：
```
P_final = w1 * Score_A + w2 * Score_B
```

问题：权重是固定的，不管样本是什么都一样的比例。太简单，没有交互建模。

### 3.2 Stacking（改进方案）

训练一个"元模型"来融合两个模型的输出：
```
Score_A, Score_B → Meta-Model（逻辑回归或小MLP）→ Final Score
```

比加权融合强：
- 可以学非线性组合
- 元模型可以学"当A高B低时"和"当A低B高时"的不同处理策略
- 但仍然是在输出层融合，两个模型本身没有联合优化

### 3.3 多视角融合模型（推荐方案）

**核心思想**：同一个样本用两种编码表示，输入一个模型，在模型内部通过Cross-Attention和Gated Fusion动态融合。

**不是**两个模型各自跑完再拼分数，而是**一个模型同时接收两种输入**，在推理过程中让两种特征"实时对话"。

**架构设计**：

```
输入层（双视角）：
  ├── 视角1：9-bit区域编码（大师兄）→ RegionalCNN编码器
  └── 视角2：9-bit连续错配编码（小师兄）→ MismatchTransformer编码器
           ↓
Cross-Attention（交叉注意力）：
  区域分支作为Query问连续错配分支："seed区你看到什么了？"
  连续错配分支回答："seed区有连续3个错配，高风险"
  → 两个分支在推理过程中实时交互
           ↓
Gated Fusion（门控融合）：
  根据每个样本动态决定融合权重
  样本A：区域权重70%，错配权重30%
  样本B：区域权重20%，错配权重80%
  → 不是人定的固定比例！
           ↓
Prediction Head（预测头）
  → 最终脱靶概率
```

**创新点提炼**：
1. 多视角输入表示：同一个配对用两种互补编码表示
2. Cross-Attention：两个分支在推理中互相"提问回答"
3. Gated Fusion：每个样本的动态自适应权重
4. 端到端训练：所有模块联合优化

### 3.4 特征级融合（务实方案）

把两套编码合并成一个更长的编码，训练单一模型：
```
9-bit区域编码 + 9-bit连续错配编码（去重）→ 12-bit合并编码 → 单一模型
```

简单有效，改几行代码就能跑，适合做baseline验证。

## 第四部分：RNA-FM预训练模型分析

### 4.1 RNA-FM是什么

RNA-FM是一个RNA序列的语言模型，类似GPT但针对RNA。在2300万条RNA序列上通过"完形填空"任务预训练。

它学到的不是"RNA长什么样"，而是RNA序列中碱基之间的深层关系模式——包括碱基配对偏好、二级结构规律、功能区域暗示等。

### 4.2 RNA-FM怎么获取

完全开源免费：
- GitHub：https://github.com/ml4bio/RNA-FM
- 安装：`pip install rna-fm`
- 加载：`model, alphabet = fm.pretrained.rna_fm_t12()`
- 权重自动下载

模型规格：
- 12层Transformer，640维隐藏层，20头注意力
- ~99M参数，权重文件约380-400MB
- 只有这一个标准版本，不存在小杯/中杯/大杯

### 4.3 预训练vs先验特征的本质区别

| 维度 | 预训练（CCLMoff路线） | 先验特征（我们路线） |
|:---|:---|:---|
| 知识来源 | 从2300万条RNA序列中自动统计 | 人类分子生物学研究成果 |
| 怎么进模型 | 模型自己读书学到的 | 人类手动编码成特征 |
| 优势 | 通用、不需要人工设计 | 精准、有针对性、数据高效 |
| 劣势 | 需要海量数据和算力 | 需要领域知识、设计复杂 |
| 数据效率 | 低（需要950万样本才能好） | 高（60万样本就能好） |

### 4.4 为什么预训练这么强

1. **小样本学习效率**：RNA-FM已经懂RNA语言，微调时只需要学"脱靶预测"这个特定任务
2. **碱基表示质量**：预训练后的碱基向量（640维）编码了丰富的上下文关系，不是简单的one-hot
3. **泛化能力**：见过的序列足够多，遇到新sgRNA时能找到类似参考

消融实验证据：CCLMoff-Vanilla（无预训练）AUPRC从0.520降至0.381，下降27%。

## 第五部分：训练数据组织方式

### 5.1 数据怎么组织

**核心**：训练样本是"配对"级别的，不是"sgRNA"级别的。

所有sgRNA的所有候选位点**打平混在一起**，每个样本是独立的(sgRNA, DNA, 标签)三元组。

```
sgRNA-1的N1个样本 + sgRNA-2的N2个样本 + ... → 全部混合

每个样本：
  - sgRNA序列（20nt）
  - 候选DNA序列（20nt）
  - 标签（1=真实脱靶，0=不是脱靶）
```

### 5.2 模型到底在学什么

**不是在背"哪条sgRNA的脱靶位点是哪个"**，而是在学**"sgRNA和DNA怎么配对才会被Cas9切"**——这是一个和sgRNA身份无关的通用规律。

模型看到的输入就是sgRNA序列+DNA序列，sgRNA的具体身份已经编码在序列中了。

### 5.3 怎么验证泛化能力

**Leave-One-sgRNA-Out**：
- 训练时故意去掉某一条sgRNA的所有样本
- 只用剩下的sgRNA训练
- 用被去掉的sgRNA测试
- 如果表现好→模型学的是通用规律；如果差→模型在背答案

## 第六部分：技术路线对比与未来方向

### 6.1 三种路线对比

| 维度 | CCLMoff | 我们的融合模型 | 未来终极模型 |
|:---|:---|:---|:---|
| 先验特征 | ❌ | ✅（区域+连续错配） | ✅（更强版本） |
| 预训练上下文 | ✅（RNA-FM） | ❌ | ✅（RNA-FM） |
| 融合架构 | 简单MLP | Gated Fusion | Cross-Attention+Gated Fusion |
| 数据效率 | 低（950万） | 高（60万） | 中偏高 |
| 泛化能力 | 强 | 中 | **最强** |
| 计算需求 | 高（8×A100） | 低（2×A6000） | 中（2-4×A6000） |

### 6.2 核心哲学差异

- **CCLMoff** = 让天才少年自己读遍全世界书，学会破案（数据驱动）
- **我们的融合模型** = 请两个经验丰富的老侦探，告诉他们哪里容易出案子，让他们联手破案（知识驱动）
- **未来终极模型** = 让读了高中的学生再去上私人教师的课（数据+知识双驱动）

### 6.3 我们的硬件优势

- 服务器有两张A6000 Black GPU
- 不需要8张A100也能跑融合模型
- RNA-FM权重可以免费下载（~400MB）

### 6.4 可行的科研路线

```
Layer 1: AB加权融合 → 快速baseline
Layer 2: AB Stacking → 改进baseline
Layer 3: 端到端多视角融合模型 → 核心创新
   └── RNA-FM底座 + 先验特征注入 + Cross-Attention + Gated Fusion
```

## 第七部分：关键结论

1. **连续错配**不是单个错配的简单叠加，连续3+错配会形成DNA鼓包，对R-loop延伸产生非线性影响
2. **脱靶**不是"粘不上"，而是"粘错了地方还切了"
3. **先验特征**（区域编码+连续错配编码）= 人类几十年生物学知识的结晶，直接编码进输入
4. **预训练模型**（RNA-FM）= 从大数据中学到的通用RNA语言理解，即插即用
5. **最好的模型可能是先验+预训练的结合**，CCLMoff没有先验特征，我们有先验但没有预训练
6. **RNA-FM已开源免费**，不需要自己训练底座，下载即用
7. **多视角融合**的核心不是"拼分数"而是"让两种特征在模型内部实时对话"
8. **Gated Fusion**让每个样本有动态权重，不是固定比例
9. **训练数据按配对级别组织**，模型学的是通用配对规律，不是记住sgRNA身份
10. **Leave-One-sgRNA-Out**是验证泛化能力的金标准
