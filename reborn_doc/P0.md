## 1. P0 的定位

P0 是项目启动前的**基础设施与规范搭建阶段**，核心产出是：
1. 项目总纲 `1. 大纲拟定.md` v2（坐标约定、术语规范、Git 铁律）

3. CCLMoff 数据集审计 + RNA-FM 权重验证
4. **旧模型加权平均 baseline**：R9/DeepFocus(0.16) + C9/ConMismatch9(0.84)

## 2. 关键结果（已修正为最新信息）

### 2.1 P0 / BL0-P0-weighted-average

| 项目 | 数值 | 说明 |
|:---|:---|:---|
| 数据集 | GUIDE-seq | 不是 CCLMoff |
| 总样本 | 520,281 | — |
| observed_positive | 1,123 | — |
| unobserved_candidate | 519,158 | — |
| 划分 | 70/15/15 | train/val/test |
| 最优权重 | R9=0.16, C9=0.84 | 验证集网格搜索 |
| R9 only AUPRC | 0.8279 | DeepFocus |
